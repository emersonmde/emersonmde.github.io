# Error Signal

Personal portfolio site with a TUI (terminal) aesthetic. Built with Astro.

**Live:** [errorsignal.dev](https://errorsignal.dev)

## Quick Start

```bash
npm install
npm run dev      # localhost:4321
```

## Structure

- `/` - Projects showcase
- `/photos` - Photo gallery
- `/blog` - Blog posts
- `/about` - About page

## Features

- Terminal-style UI with Sonokai colors
- Interactive command prompt (try `help`)
- Vim-style navigation (Escape for normal mode, j/k to navigate)
- Expandable project cards with GitHub/demo links

## Build & Deploy

```bash
npm run build    # Production build to ./dist
```

Deploys automatically via GitHub Actions on push to `main`.
